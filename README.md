# Ahorcado de papel

Juego de ahorcado responsive hecho con Flutter. Incluye teclado en pantalla y físico, palabras con tildes, pistas, estados de victoria/derrota y seis intentos.

## Ejecutar

```bash
flutter pub get
flutter run -d chrome
```

## Verificar

```bash
flutter analyze
flutter test
```
